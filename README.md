# Python Uptime Monitor

## EN

**Description**
- Python automation script for proactive IT infrastructure monitoring. Checks website uptime, HTTP status codes, and generates automated logs.

**Installation**
- Ensure your Python virtual environment is active (or create a new one), then run the following command in your terminal:
```bash
pip install -r requirements.txt
```

## PT-BR

**Descrição**
